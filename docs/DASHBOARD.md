# Opening the offline dashboard

The HTML at `evidence/publication_atlas/index.html` is an **offline viewer** built from the published aggregate MIMIC demo figures. It is not a deployed website and does not send patient data to any hosted service.

GitHub's iOS application and code browser show HTML **source** instead of executing scripts. This is an intentional viewer limitation, not evidence that the chart build failed.

To view the dashboard, [download the repository ZIP](https://github.com/Farshidbagheri/Observation-aware-ehr-data/archive/refs/heads/main.zip), extract it, and open `evidence/publication_atlas/index.html` in a browser. Keep the adjacent `figures/` SVG files in place. On a desktop, open directly in Safari, Chrome, or Firefox; on mobile, use an HTML viewer supporting local relative files or open the figures individually in the GitHub app.

For immediate mobile viewing, the best-supported interface is the [inline README figures](../README.md#results-gallery). Enabling a hosted dashboard or GitHub Pages would require deliberate repository visibility and institutional data/IP review; it is **not** enabled here.
