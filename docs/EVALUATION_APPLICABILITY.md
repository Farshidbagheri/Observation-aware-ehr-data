# Evaluation applicability and figure provenance

**Authoritative input:** `CLINICAL_AI_VISUALIZATION_EVALUATION_STANDARD.md` and `CLINICAL_AI_VISUALIZATION_EVALUATION_STANDARD.json` supplied for the project (2025–2026 evidence edition, schema v1.0.0). This is their project-specific application, **not** a substitute for the original documents.

## Current study profile: `no_predictive_model`

This repository currently contains an **observation-process / decision-time data-engineering study**, run on the *public* MIMIC-IV-ED Demo 2.2 and MIMIC-IV Clinical Demo 2.2. It does NOT contain an adjudicated sepsis timing-outcome cohort or a validated model. In particular, ED charttime and hospital storetime do not establish clinician viewing time, and Pyxis does not document administration.

## Data contract & limitations

- **Unit of analysis:** ED stay for observation-by-time; source record for completeness and storage-lag analyses.
- **Time zero:** recorded ED arrival; NOT sepsis onset or antibiotic decision time.
- **Source population:** public selected 100-person demonstration subset; 222 ED stays; not representative of overall MIMIC or MetroHealth populations.
- **Clinical reference standard / outcome / horizon:** not available for this descriptive task.
- **Treatment:** no first IV antibiotic administration extraction and no causal policy estimate.
- **Sampling:** irregular; repeated within-stay values; temporal bins and denominators reported.
- **Availability:** unknown except labeled charttime/storetime proxies in the underlying pipeline.
- **Sites and external cohort:** one public demonstration setting; external validation not performed.
- **Privacy:** public aggregate figures; no individual timelines, subject IDs, rare patient combinations, or patient-level CSV exports.
- **Uncertainty:** Patient-cluster percentile bootstrap with 2,000 resamples and seed 2026 over the 54 observed patients with vitalsign rows. Describes the selected demo's row-weighted field completeness and does not provide general-population confidence.
- **Software:** Python 3.11 in GitHub Actions; install `.[analysis,test]`, download/verify datasets via `scripts/fetch_demo.py`.
- **Sources:** PhysioNet MIMIC-IV-ED Demo v2.2 DOI [10.13026/jzz5-vs76](https://doi.org/10.13026/jzz5-vs76); MIMIC-IV Clinical Demo v2.2 DOI [10.13026/dp1f-ex47](https://doi.org/10.13026/dp1f-ex47).

## Research and publication gates

- `G01/G04/G06/G07/G11`: no fabricated metrics; task-fit only; no unsupported causal/clinical claims; figure adaptations labeled.
- `G02`: modeling splits **not applicable** absent a trained model; enforce patient-level and temporal separation before extending.
- `G03`: no patient-level exports, subject IDs or raw rows in gallery.
- `G05`: every applicable descriptive estimate has its unit and denominator; model metric requirements await labels.
- `G08`: SVG vector + PNG raster of same underlying plot; explicit units, sample counts, and caption.
- `G09`: cluster units and resampling seed disclosed; intervals are not externally population-representative.
- `G10`: pinned upstream **dataset versions** and SHA256 manifests; pip-version lock still needed before archival release.
- `G12`: no decorative 3D visualization; coherent two-dimensional multipanel figures.

**DOI/release threshold:** Rerun the full CI pipeline and independently inspect source tables, source hashes, all figures, small-cell restrictions and consent/licensing. The presence of a dashboard is not a publication or clinical validation claim.
